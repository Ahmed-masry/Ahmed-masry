# Ahmed Elmasry

Electronics & Communications Engineering graduate focused on digital IC design, RTL development and functional verification.

I graduated from Al-Azhar University in July 2025. My academic projects and training cover Verilog/SystemVerilog, processor and interface RTL, clock-domain crossing, synthesis and FPGA implementation.

## Selected public projects

- [RISC-V processor with data cache](https://github.com/Ahmed-masry/RISC-V-With-Cache-Memory): processor RTL, a direct-mapped data-cache subsystem and testbenches.
- [UART transmitter](https://github.com/Ahmed-masry/UART_TX): modular transmitter RTL with configurable parity and a testbench containing frame checks.
- [SPI interface](https://github.com/Ahmed-masry/SPI): master/slave interface RTL with a multi-slave top-level and stimulus testbench.

These are educational source projects. See each repository for its files and validation status; the presence of a testbench is not a claim of a passing regression.

## Graduation project

**Design, Verification and FPGA Prototyping of a MIPI D-PHY Transceiver**, a team project sponsored by Si-Vision.

As team leader, my work included defining the digital TX/RX architecture, implementing the TX and High-Speed RX RTL in Verilog, running lint/CDC/RDC and synthesis, and leading FPGA SoC integration and hardware debugging on Artix-7. The wider team project also included UVM-based verification and MATLAB reference modeling.
